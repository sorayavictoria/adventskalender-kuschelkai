# Kais Adventskalender 🎄

Ein digitaler Adventskalender mit 24 Türchen, Liebesbriefen und Rätseln.

## Links

- **Für Kai:** `https://<dein-github-name>.github.io/adventskalender-kuschelkai/`
- **Vorschau für dich (alle Türchen offen):** dieselbe Adresse mit `?vorschau` am Ende
- **Einen bestimmten Tag testen:** `?vorschau&heute=8` (tut so, als wäre der 8. Dezember)

## Was liegt wo?

| Datei | Inhalt |
|---|---|
| `index.html` | Die Seite selbst |
| `css/style.css` | Farben, Schriften, Aussehen |
| `js/briefe.js` | **Die 24 Liebesbriefe** und welche Fotos bei welchem Brief erscheinen |
| `img/` | Eure Fotos |
| `js/raetsel.js` | Die Rätsel und Lösungen (verschlüsselt, damit Kai nicht schummeln kann) |
| `js/spiele.js` | Die Spiele |
| `js/app.js` | Kalender, Datum, Speichern, Effekte |
| `js/bilder.js` | Kleine Zeichnungen |

## Einen Brief ändern

1. Auf GitHub `js/briefe.js` öffnen
2. Auf den Stift (Bearbeiten) klicken
3. Text zwischen den `` ` `` Zeichen ändern
4. Unten auf „Commit changes“ klicken. Nach ein bis zwei Minuten ist die Änderung online.
